# Security Policy

## Supported Versions

Security fixes are provided for the latest version on `main` and the current production deployment.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting in the repository's **Security** tab, or email alficodess@gmail.com with **[Screeny security]** in the subject.

Include what you found, where it occurs, steps to reproduce it, and the potential impact. A clear proof of concept helps, but do not include real user data or secrets.

Screeny is maintained by one person. I aim to reply within a few days, but cannot promise a fixed response or resolution timeline. Please give the maintainer a reasonable amount of time to investigate and address a report before public disclosure.

When researching, test only your own local setup or account. Do not run scanners or load tests against production, access or modify other people's data, or disrupt the service.

Copyright and takedown requests are handled separately; see [NOTICE.md](NOTICE.md). Please use the regular issue tracker for non-security bugs.
